###  Controle Financeiro Pessoal

Aplicação de linha de comando desenvolvida em Python e SQLite para gerenciamento de receitas e despesas.

**O que desenvolvi:**
- Cadastro, listagem e exclusão de movimentações.
- Consulta de receitas, despesas e saldo.
- Persistência de dados com SQLite.

- Testes automatizados com unittest.
